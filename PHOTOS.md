# Website photos

Every photo on www.chudleighhealth.com, where it appears and what it is for.
Photos live in the `images` folder. Replacing a file with a new one of the **same name**
updates it everywhere it is used.

**Easiest way to replace one:** send the new photo to Claude and say which file it replaces
(for example "this is the new hero.jpg"). It will be resized, named and uploaded for you.

**Sizes:** most photos show as squares, so square photos at least 800 × 800 pixels work best.
Team photos: square, at least 600 × 600. Keep each file under about 300 KB.
